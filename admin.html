🛠️ MongoDB Tools & Migration

Use these one-click tools to migrate browser data or pre-populate MongoDB with initial Sanmarga content:

🔄 Sync Local Storage ➔ MongoDB

Takes any demo enquiries, donation pledges, and gallery photos stored in this browser and pushes them directly into MongoDB collections.

🌱 Seed Default Balaga Data

Populates empty MongoDB collections with standard Sanmarga gallery moments, community impact numbers, sample enquiries, and default credentials.

💡 How to use MongoDB Atlas (Free Cloud Database): 1. Create a free account at mongodb.com/atlas.
2. Create a free M0 Shared Cluster.
3. In Database Access, add a database user with username and password.
4. In Network Access, click "Add IP Address" & select "Allow Access from Anywhere" (0.0.0.0/0).
5. Click Connect ➔ Drivers (Python), copy the URI string, replace <password> with your password, and paste above!
